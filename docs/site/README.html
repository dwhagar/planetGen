Folders

Folder What it holds Written by
reference/ How to use and configure the program: api.md (JSON API), cli.md (every command), config.md (config.json; one block is generated by planetgen config docs), database-schema.md, html-interface.md (the web pages), system-file-format.md and example-systems.md, atmosphere-data-model.md (what a body stores about its air and where each value comes from), bulk-composition-data-model.md (what a body is made of in bulk and how its mass, radius, density and gravity follow), atmosphere-colour.md (how a body's atmosphere colour is worked out), testing.md, ci-runners.md hand
REFERENCES.md and REFERENCES.html Every paper, dataset and catalog the project builds on, in AAS/ADS style with links; written by scripts/build_references.py generated
deployment/ Putting it on a server: README.md is the start, then Apache, nginx, Caddy, macOS, PaaS and fail2ban guides, server-checklist.md and WINDOWS.md hand
design/ Design notes, one folder per topic; design/README.md lists every note with its status. Folders: architecture/, galaxy/, systems/, generation/, composition/, habitability/, orbits/, interface/, operations/, research/ (with research/imported/, Boss's own research documents) hand
plan/ The plan (README.md names the one source for each kind of fact): release-roadmap.md, lanes.md (what each build lane is doing), notes.md (decisions for Boss), execution-notes.md, progress-ledger.md, issue-groups.md, todo-number-map.md (old numbers and the next free ID of each category), intergalactic-space-plan.md; releases/ has one file per version hand (TODO thread)
generated/ Pages built by scripts, never edited by hand: the plan pages, the code map, and the code inventories (every database column and API route). See generated/README.md script
history/ The record of what was chosen, dropped and how the work moved: timeline, release headlines by month, Boss's decisions by month, every item's life, what was retired or closed, and each design note's items. A snapshot built from git by scripts/build_history.py (DOC.117) script (snapshot)
archive/ Designs and reviews that were replaced; kept as history hand

Where does a new file go

  • A design note: the topic folder under design/, plus a row in design/README.md.
  • A guide to using or running the program: reference/ or deployment/.
  • A planning note: plan/. A page a script builds: its script writes it into generated/.
  • A note about a design that was replaced: archive/.
