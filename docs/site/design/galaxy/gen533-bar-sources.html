Status: research read-out, 2026-10-17, written by a read-only research worker for the GEN.533 build (Core 1). Its proposed draws are implemented in galaxy/structure_draw.py (draw_bar). The rule applied to every conflict is Boss's: verified beats second-hand, the newest of two verified wins, the widest range wins where both are in question. Status words: READ = number is in the paper text or a table printed in the PDF. FIG-LABEL = number printed inside a figure panel, extracted as text. FIG-ONLY = visible only as a plot (not used for numbers). ABSTRACT = abstract only. COMPUTED = I computed it from a table in the paper or its VizieR copy (method named). Galaxy 'stage' in this file: early = Sa-Sb, late = Sc and later (papers use other cuts; each row says which).

Mock-observation setup bar angle drawn uniformly in (0, 90 deg) from the line of nodes; mock PAs uniform 0 to 180 deg [R1288] Sect. 5 (simulations); [R0045] Sect. 4 READ (assumption)

No paper in this set states a measured uniform distribution; every statement is an assumption or expectation. By rotational symmetry the bar angle against any fixed reference direction is uniform on [0,180) unless the host has an external alignment (not found). Need for a measured test: bar PA relative to a fixed sky axis for a face-on, large-sample catalogue (e.g. Diaz-Garcia/Herrera-Endoqui PA columns, not tested here). The Milky Way 27 deg is one draw.

  1. Bar present: p = 1/(1+exp(-(-82.2+17.1m-0.88m^2))) for BOTH early and late (0.69, 0.69, 0.58, 0.46, 0.36, 0.21 at m = 9.48, 10.0, 10.5, 10.8, 11.0, 11.3).   2. Bar in-plane axis ratio y0/x0: draw e from a normal, centre 0.53, SD 0.15, clamp e to 0.15 to 0.90, then y0/x0 = 1-e (so mean 0.47, clamp 0.10 to 0.85).   3. Bar vertical axis ratio z0/x0, two branches:

  4. Unbarred bulge axis ratios (y0/x0 = B/A, z0/x0 = C/A): B/A normal centre 0.83, SD 0.21, clamp 0.30 to 1.00 ([R0902] Table C.1, N=41, COMPUTED from the printed table; MA08 centre 0.85 and MA08 floor B/A>=0.5 agree on the centre but not the floor; clamp uses the wider table range).
