## Where does a new file go

- A design note: the topic folder under `design/`, plus a row in [design/README.md](design/README.md).
- A guide to using or running the program: `reference/` or `deployment/`.
- A planning note: `plan/`. A page a script builds: its script writes it into `generated/`.
- A note about a design that was replaced: `archive/`.
