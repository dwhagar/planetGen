Main reordering decisions

  • Nothing is held (Boss, 2026-10-09 07:54Z), so all 76 non-bug Phase 1 items are in the lane lists, unblockers first. Within each lane the items that free the most other work come ahead of the leaves: GEN.84 (frees 17), OPS.8 (15), OPS.13 and GEN.58 (14), GEN.56 (14), DB.7 (13), NAV.10 (12), ADM.18 (10), GEN.106 (8). The habitability chain (GEN.84 to GEN.89, GEN.83) and the tech-level design (POP.8) now sit on Foundations 2 right behind GEN.56 and GEN.106; Repeatable Galaxy's GEN.57, TEST.77 and GEN.59 stay last.
  • Orbital updates moves to the front, and GEN.106 stays on Foundations 2 right after GEN.56 (Boss's decision on the card). GEN.106 goes ahead of GEN.104 because it unblocks GEN.107, GEN.108, GEN.115, GEN.109 and GEN.105; GEN.104 depends on nothing. Boss moved every Foundations 3 item into Foundations 1 and 2, so GEN.104 and the phase 2 orbital chain (GEN.115, GEN.109, GEN.110, ADM.36, GEN.105) now run on Foundations 2 behind GEN.106. Everything after GEN.106 in this group is proposed, not yet approved.
  • GEN.56 is merged (PR #791). Every generation draw now goes through planetgen/util/draw.py, so GEN.127 is unblocked and GEN.57 can start, but it still goes last. Foundations 2 moves on to GEN.106.
  • New random draws use the helpers in util/draw.py. A test fails if a generator imports random, secrets or uuid directly, so GEN.98, GEN.100 and GEN.104 have to use them.
  • The map bugs go first in the Bugfix lane. MAP.136 to MAP.138 (MAP.135 is merged) touch the same map files as the Maps group, so they land before Foundations 2 starts Maps. Foundations 2 and the Bugfix lane never edit those files at the same time.
  • Nearby search and Routing go to Foundations 1 after GEN.100, in that order. GEN.100 is also the one outside blocker of NAV.47.
  • The small blockers of Repeatable Galaxy (DB.7, OPS.8, OPS.13, OPS.14, ADM.18, GEN.58) are filler work. They depend on nothing and take little time, so any lane that has a gap takes them. They are what keeps GEN.59, OPS.12 and GEN.55 from queuing behind each other later.
  • NAV.10, NAV.12 and GEN.84 do not hang off seeded draws. NAV.10 and NAV.12 only read stored data, and GEN.84 is a design note with no draws. The items that do depend on the draws are the generation items that add them: GEN.104, GEN.85 to GEN.88, GEN.99, GEN.101, GEN.127 and GEN.128 to GEN.130.

Boss wants this done but at the lowest priority, so the plan clears what blocks it first and puts the big step, GEN.57, at the end.

What blocks it

  • DB.7 (the version that generated each sector; Alembic) blocks ADM.18, OPS.14 and OPS.12.
  • OPS.8 → OPS.13 → OPS.14 (Apache reload, version-key history, key-mismatch warning) block ADM.18, OPS.17, OPS.15 and OPS.12.
  • ADM.18 (creation settings as a JSON file) blocks GEN.59, GEN.61, ADM.19 and OPS.12.
  • GEN.58 (a fingerprint of generated content) blocks TEST.77, GEN.59, DB.9, OPS.15 and OPS.12.
  • GEN.56 (every draw from the derived seeds) is merged (PR #791), so it no longer blocks anything. GEN.98, GEN.100 and GEN.104 use its helpers from the start.

What it blocks

  • GEN.56 blocks GEN.57 and GEN.59. GEN.57 blocks TEST.77, DB.9, API.17 and OPS.12. TEST.77 blocks OPS.12, which blocks GEN.55 (the end goal).
  • GEN.101 (fill order) and GEN.99 (nebula backfill) do not need it, but they should use the same helpers.
