### Data tables carry no licence

Rule (Boss, 4:41 to 4:42 PM EDT 2026-10-22, relayed 4:42 PM EDT as the lane's clock reads): a data table has no licence column and no loader or test checks one. Licence information lives in one file in the repo root, `DATA-LICENSE.md` (Boss, 4:46 PM EDT 2026-10-22; the project's own `LICENSE.md` stays as it is, and GEN.623 creates the new file and removes the existing columns and checks from the gas table, the element table and the possibility-table loader). A lane that builds a new table (GEN.427, GEN.478, GEN.458, GEN.495) leaves the column out, and a lane with an open table that carries a licence field (Blocker 2, Core 4) drops it when GEN.623 merges. This does not touch source and citation fields: every number still states where it was read.
