**Headline:** The System Map and the sector pages name things through the same label engine as the Galaxy Map.

### Changed
- **System Map names (MAP.231).** The names of the stars, planets and moons on the System Map diagram are placed by the same label engine as the Galaxy Map's (none over another, none over a marker, a name that cannot fit is left off), and the 3D system view names its bodies through it too. The Menu on the system page has a new "Body names" switch (in the address as `hide=label-body`) that shows or hides them on both views.
- **Sector page names (MAP.231).** A sector's own page gets the Labels group in its Menu, with System names and Sector names, so the names of its stars can be hidden like everywhere else. The old text sprites of the Sector Map scene (compass and neighbouring sector names, never reached since the Galaxy Map draws the neighbours itself) are gone, so no second label code is left.
