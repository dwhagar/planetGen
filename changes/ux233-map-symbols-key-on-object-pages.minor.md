**Headline:** The star system page now shows the map's symbols beside its worlds, with the collapsed "Map symbols" key under them.

### Added
- **Map symbols on object pages (UX.233).** In the "Stars and bodies" tree of a star system page (and the tree of a star or planet page) a habitable world, an uninhabitable world, a gas giant and an asteroid belt carry the same symbol the Galaxy Map gives them, coloured by habitability score as on the map. When a page draws at least one, a collapsed "Map symbols" panel with the same seven lines as the Galaxy Map's key follows the tree; a page with no symbol has no key. The inhabited-world symbol is not drawn on these pages yet because a tree row does not carry the facts it needs.
