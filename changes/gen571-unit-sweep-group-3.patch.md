**Headline:** The planet, magnetism, hydrosphere and star-radius code now converts lengths, times, pressures and densities through the one unit registry, with the same numbers.

### Changed
- Physics files `planets`, `magnetism`, `hydrosphere`, `habitability_world`, `regional_temperature`, `stellar_evolution`, `king`, `bulk_mass`, `metallicity`, `hii`, `sector_path`, generation files `star`, `system`, `phenomena/rogue`, `phenomena/compact_remnant`, `phenomena/asteroid_field`, `phenomena_plausibility` and `web/maps/systemscene` call `unit_registry.converter` for their AU, km, m, hour, year, Gyr, Pa, kPa, kg/m3, g/cm3 and cm-3 conversions (GEN.571, third file group). Every replaced expression gives the same float bit for bit, pinned by `tests/test_unit_converters.py`. Sites whose operation order would change the last digit (the parsec and light-year helpers of `physics/units.py`, the sector `AU_TO_LY` product, `position.py`, `lensing`) are left for the epoch-changing pass.
