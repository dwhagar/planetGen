Changing the other settings

The settings marked with a reason cannot be changed from this page. The server's own file, config.json, holds them: edit it on the server, or run python3 -m planetgen.cli.config set NAME=VALUE (the name is the Setting shown under Details), then restart the web server. An Owner-only setting is changed by the Owner.
